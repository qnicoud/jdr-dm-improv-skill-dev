06 · Connect the Story en cours (S05-6)

(a) panneau déployé avant clavier, 3 sur 5 reliés ; (b) panneau compact, clavier ouvert ; (c) variante 200 %. Le chevron plie et déplie ; toucher une case la coche ou la décoche.

Annotations · Connect the Story

Rôles de couleur

  • Élément relié : secondaryContainer + contour primary 2 dp + case pleine primary + coche. Non relié : surfaceContainerLow, case à contour outline.
  • Mots reliés dans le texte : tertiaryContainer + soulignement 2 dp (phare, cuillère).
  • Zone épinglée : surfaceContainer ; minuteur : surfaceContainerHigh.

Tailles

  • Déployé : 5 lignes de 56 dp mini (texte 16 sp, catégorie 12 sp), case 24 dp dans une cible de 48 dp. Environ 56 % de l'écran avant clavier, car le texte à écrire reste visible dessous.
  • Compact (b) : 2 rangées de puces de 44 dp, zone épinglée environ 164 dp sur 520 (32 %). Texte de puce 12 sp sur 2 lignes maximum.
  • 200 % (c) : une seule ligne (minuteur, pause, chevron) plus le compteur à 100 % ; zone épinglée plafonnée à 126 dp, défilement interne si on la déplie.

Accessibilité

  • Auto / à la main : en déployé, le mot « auto » ou « à la main » est écrit dans la ligne ; en compact, un point discret signale « auto » et TalkBack lit « auto ».
  • Verrou manuel : l'icône cadenas s'affiche sur un élément décoché à la main pour expliquer pourquoi la détection ne le recoche pas (état non dessiné sur les écrans, décrit dans le design system §5.8).
  • Un élément coché par erreur se décoche en un toucher : essayez les cases.
  • Compteur « 3 sur 5 reliés », jamais « 3/5 manqués ».
  • Les cinq éléments restent atteignables au pouce dans les trois états ; le texte complet de chaque élément est lu par TalkBack même quand l'affichage est réduit.
